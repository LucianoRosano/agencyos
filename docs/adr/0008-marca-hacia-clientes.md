# ADR 0008 · Marca: AGENCYOS adentro, "Luciano Rosano" hacia los clientes

**Estado:** aceptada · 04/11/2026 (pedido de Luciano)

El sistema se llama AGENCYOS. Los documentos que ve un cliente (presupuestos, constancias) usan la marca **Luciano Rosano**, con un monograma tipográfico "LR", y los datos de contacto de Configuración → Agencia.
